尚未連線
使用桌面 Chrome 或 Edge，從 localhost 或 HTTPS 開啟。
操作前請拆除螺旋槳、關閉 Betaflight Configurator，並確認 RotorREC 有供電。完成後請將飛控重新上電以恢復遙控與 OSD。

首次使用與飛前檢查

  1. 首次安裝：依板型用 ESP USB 安裝完整雙槽韌體，再接 5V、GND 與交叉的 TX／RX。
  2. 設定飛控：啟用所接 UART 的 MSP 115200，將遙控開關或瞬時按鍵指派至 USER；ARM 模式會讀取飛控解鎖狀態。
  3. 選擇相機協定並配對，確認影片模式、SD 卡與電量。以實際相機畫面確認開始及停止錄影。
  4. 離開維護後重新上電飛控，確認 OSD 有新鮮狀態、開關／ARM 起停、延遲取消與斷線恢復。

選擇的是已實作的通訊協定。GoPro 與其他型號的相容性仍需實機驗證；配對時可能需要在相機確認。維護前讓相機保持待機。

基本設定
錄影方式與警告

Button／Combi 請在 Betaflight 將瞬時按鍵指定至所選 USER。Off 仍可使用相機本身或 BOOT 按鈕。停錄要求不等於已存檔，斷電前請確認相機已停止。

4 行模式需要在 Betaflight 放置 Custom Messages 1–4。

編輯 OSD 顯示內容

可用欄位：{state} 狀態、{battery} 電量、{elapsed} 計時、{remaining} 剩餘時間、{format} 格式、{space} 容量、{mode} 模式。可加英數文字，每行最多顯示 16 格；留空使用內建行。錯誤與停錄倒數固定優先顯示於第一行。

第 3、4 行需選擇四行模式，並在 Betaflight OSD 放置 Custom Messages 3、4。畫面位置由飛控設定。

手機 Wi-Fi 地面維護

先讀取並保存這台模組的連線資訊，再進入 Wi-Fi。連上模組熱點後，以手機瀏覽器開啟 http://192.168.4.1；若手機顯示無網際網路，選擇保持連線。Wi-Fi 模式停用相機與飛控控制，僅供地面使用。

已保存密碼後，正常模式也可按住 BOOT 8 秒再放開進入 Wi-Fi。C6 顯示連線資訊，C3 藍燈閃爍；長按 BOOT 放開退出。十分鐘無操作且沒有進行中工作會自動返回正常模式。一般斷電重開也會離開 Wi-Fi。

    

      
03 / FIRMWARE
更新 RotorREC 韌體
雙槽 OTA

      
      
選擇由 RotorREC pack 工具產生的更新 ZIP。不要選 bootloader、factory 或單獨的 BIN。

      
尚未開始

      
      
只更新 RotorREC，不更新飛控。傳送 100% 後仍須完成校驗及重啟驗證。請保持分頁在前景、避免電腦睡眠，並使用可信任的韌體來源。

    

    
04 / ACTIVITY
操作紀錄
準備就緒。

    
移除相機與重設

      
      
清除配對會刪除三種協定保存的相機與藍牙配對，保留設定並開啟 Link Pause。恢復出廠另會清除設定、OSD 版面、待停錄工作及 Wi-Fi 密碼。

      
      

      
Wi-Fi 出廠重設後回到正常模式，並清除舊密碼；此連線無法確認完成。請以飛控 USB 重新讀取狀態。C6 可在開機後按住 BOOT 8 秒並放開，再查看新連線資訊。
